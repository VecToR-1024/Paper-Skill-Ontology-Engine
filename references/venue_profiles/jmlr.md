# JMLR (Journal of Machine Learning Research)

- **类型**：期刊（ML 顶刊）
- **领域**：机器学习

## 篇幅结构

| 项 | 说明 |
|----|------|
| 正文限制 | 无硬性限制，典型 20-40 页 |
| 附录 | 正文内包含，不需分离 |
| 结构 | IMRaD + 完整证明/算法细节 |
| 摘要 | ≤ 300 词 |

**结构惯例**：
- 期刊论文期待：完整的理论证明、详尽的算法描述、系统的实验、深入的讨论
- 滚动审稿制——可多轮修订，但首轮质量决定命运
- Related Work 需覆盖更广（不仅是近2年）
- 实验部分可包含更全面的消融和敏感性分析

## 表达偏好

| 维度 | 偏好 |
|------|------|
| 人称 | "we" |
| 语态 | 主动优先 |
| 标题 | 信息型为主，正式度高于会议论文 |
| 风格 | 详尽、正式、自包含（读者无需查附录即可理解核心方法） |

## 红线

1. **深度不足**：期刊期待的不是 "conference paper + 2 pages"——需要显著更深的理论/实证贡献
2. **贡献不如会议论文**：如果同一工作的会议版已经足够，期刊版必须有实质性的新增内容
3. 其余同 NeurIPS/ICML

## 标题风格

- **主导模式**：信息型，更正式
  - "Method: A Framework for Task" — 期刊式冒号标题
  - 设问句标题极少（比会议论文更正式）
- **禁止**：空转标题

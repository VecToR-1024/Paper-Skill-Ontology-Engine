# ICCV (International Conference on Computer Vision)

- **类型**：会议（CV 顶会）
- **领域**：计算机视觉

## 篇幅结构

| 项 | 说明 |
|----|------|
| 正文限制 | 8 页（含参考文献） |
| 附录 | supplementary material |
| 结构 | IMRaD，图密集型 |
| 摘要 | 无硬性限制 |

**结构惯例**：与 CVPR 基本一致。ICCV 与 CVPR 同级，审稿标准相当。两年一届。

# ICML (International Conference on Machine Learning)

- **类型**：会议（ML 顶会）
- **领域**：机器学习

## 篇幅结构

| 项 | 说明 |
|----|------|
| 正文限制 | 8 页（含参考文献） |
| 附录 | 无限制 |
| 结构 | IMRaD |
| 摘要 | 无硬性限制，建议 ≤ 200 词 |

**结构惯例**：与 NeurIPS 基本一致。ICML 对理论贡献的接受度略高于 NeurIPS——纯理论论文（无实验）在 ICML 比在 NeurIPS 更容易被接受。

## 表达偏好

| 维度 | 偏好 |
|------|------|
| 人称 | "we" |
| 语态 | 主动优先 |
| 标题 | 信息型 + 方法论型 |
| 风格 | 精确、严谨。理论论文接受正式程度高于实证论文 |

## 红线

与 NeurIPS 一致：实验不足 / overclaim / novelty 不足 / related work 遗漏。

**ICML 特有**：理论论文若定理声明有误或证明不完整 → 直接拒。

## 标题风格

- **主导模式**：方法驱动型 + 理论型
  - "Method Name: Key Property" — 常见
  - "On the X of Y" — 理论论文常用（"On the Convergence of Adam"）
- **禁止**：空转标题

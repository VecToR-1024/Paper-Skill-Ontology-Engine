# ICLR (International Conference on Learning Representations)

- **类型**：会议（ML 顶会）
- **领域**：机器学习 / 表征学习

## 篇幅结构

| 项 | 说明 |
|----|------|
| 正文限制 | 8 页（含参考文献） |
| 附录 | 无限制 |
| 结构 | IMRaD |
| 摘要 | 无硬性限制 |

**结构惯例**：
- 与 NeurIPS/ICML 类似，但 ICLR 更看重 insight 和 conceptual novelty
- 纯实证 benchmark 论文在 ICLR 不如在 NeurIPS 好发
- 有新视角/新问题设定的论文在 ICLR 可能更受欢迎

## 表达偏好

| 维度 | 偏好 |
|------|------|
| 人称 | "we" |
| 语态 | 主动优先 |
| 标题 | 偏概念型，可接受更具启发性的标题 |
| 风格 | 接受范围比 NeurIPS 略宽——可接受更 conceptual/visionary 的 framing |

## 红线

1. **novelty 不足**：ICLR 对 incremental improvement 的容忍度低于 NeurIPS
2. **insight 缺失**：即便实验做得好，没有 "why it works" 的深刻分析也会被拒
3. 其余与 NeurIPS 一致：实验不足 / overclaim / related work 遗漏

## 标题风格

- **主导模式**：概念型 + 方法驱动型
  - 比 NeurIPS 更接受设问/概念型标题 — eg. "Why Does Unsupervised Pre-training Help?"
  - 方法命名型也更常见——ICLR 历史上产生了许多方法范式命名（GAN, VAE 变体等）
- **可接受**：略长的标题，如果传达了独特概念
- **禁止**：空转标题

# Nature Machine Intelligence

- **类型**：期刊（Nature 子刊，综合顶刊）
- **领域**：人工智能 / 机器学习 / 机器人

## 篇幅结构

| 项 | 说明 |
|----|------|
| 正文限制 | 约 6-8 页（含图表），Methods 单独放正文后 |
| 附录 | Supplementary Information 无限制 |
| 结构 | Introduction → Results → Discussion → Methods |
| 摘要 | 150-200 词，需包含背景/问题/方法/主要发现 |

**结构惯例**：
- Nature 系列独特结构：Results 是主体（不是 Experiments），Discussion 是最后
- Introduction：第 1 段 = 大背景（为什么这个问题重要），第 2 段 = 现有方法的局限，第 3 段 = 本文做了什么、为什么不同
- Results 内分多个子标题，每个子标题是一个 "finding"
- Methods 在正文中简要描述，详细步骤可放 SI
- 图至关重要：Nature 系列的图需要在脱离正文的情况下仍能理解
- 通常 3-5 个主图 + 若干 Extended Data 图

## 表达偏好

| 维度 | 偏好 |
|------|------|
| 人称 | "we" |
| 语态 | 主动优先，但被动在 Methods 部分常见 |
| 标题 | 宣告型，信息丰富，可读性强，不技术化 |
| 风格 | **面向广泛学术读者**——不能假设读者懂你的子领域。每个概念首次出现需解释。可以写得更"故事化"，但不能牺牲精确性 |

## 红线（Desk Reject 致命原因）

1. **影响力不足**：Nature 系列的第一拒因永远是这个——这项工作的受众只有这个子领域的人吗？如果是 → 拒
2. **过于技术化**：标题/摘要/Introduction 如果充满领域黑话，编辑直接拒——"这种细节应该去投专业期刊"
3. **novelty 不跨领域**：Nature 期待的方法创新往往对多个领域有启发意义
4. **overclaim** 或不精确：在大众读者面前犯科学性错误比在专业会议上更致命
5. **结构不符合 Nature 格式**：Nature 编辑在格式筛选阶段就会拒掉不符合结构的投稿

## 标题风格

- **主导模式**：宣告型 + 可读性强
  - 句式：完整宣告句 — eg. "Deep learning enables accurate weather forecasting"
  - 不用冒号式技术标题（"XYZNet: A Novel Architecture for..."）——这是 Nature 编辑会直接拒的标题类型
- **标题要素**：
  - 含动词（enables, achieves, reveals, predicts）
  - 含具体域（任务或问题领域）
  - 不含方法名、不含模型名、不含领域黑话
  - ≤ 15 词
- **反例**："A Hierarchical Multi-Scale Transformer-Based Framework for Long-Range Weather Forecasting with Auxiliary Loss Functions"
- **正例**："Deep learning enables skillful global weather forecasts at 1 km resolution"
- **禁止**：冒号式标题、方法名式标题、含有 "novel"/"new" /"improved" 等自评词的标题

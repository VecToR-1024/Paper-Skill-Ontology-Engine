# EMNLP (Conference on Empirical Methods in Natural Language Processing)

- **类型**：会议（NLP 顶会）
- **领域**：自然语言处理

## 篇幅结构

| 项 | 说明 |
|----|------|
| 正文限制 | 8 页（含参考文献） |
| 附录 | 无限制 |
| 结构 | IMRaD + Limitations |
| 摘要 | ≤ 200 词 |

**结构惯例**：与 ACL 基本一致。EMNLP 更偏重实验驱动——实证方法型论文占比高于 ACL。

## 表达偏好

| 维度 | 偏好 |
|------|------|
| 人称 | "we" |
| 语态 | 主动优先 |
| 标题 | 偏实证型，常见："Method for Task" 或 "Does X Help Y?" |
| 风格 | 比 ACL 略更接受实验密集型论文（大量 ablation + analysis 是加分项） |

## 红线

1. **实验不扎实**：EMNLP 审稿人比 ACL 更看重实证严谨性——单个数据集、无显著性检验会被严批
2. **贡献模糊**：纯 negative result 需要极强分析才被接受
3. 其余与 ACL 一致（overclaim / 不可复现 / Related Work 不全 / Limitations 敷衍）

## 标题风格

- **主导模式**：信息型 + 实证设问型
  - "Does X Help Y? An Empirical Study" — EMNLP 特有多于 ACL
  - "Method for Task" — 与 ACL 相同
- **禁止**：空转标题（"A Study of..."）

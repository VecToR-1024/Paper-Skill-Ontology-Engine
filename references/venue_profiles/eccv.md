# ECCV (European Conference on Computer Vision)

- **类型**：会议（CV 顶会）
- **领域**：计算机视觉

## 篇幅结构

| 项 | 说明 |
|----|------|
| 正文限制 | 14 页（含参考文献，ECCV 2024 起） |
| 附录 | supplementary material |
| 结构 | IMRaD，图密集型 |
| 摘要 | 无硬性限制 |

**结构惯例**：
- ECCV 2024 起页数增加到 14 页——比 CVPR/ICCV 更宽松
- 结构与 CVPR/ICCV 一致，但额外页数可用于更详细的方法描述或更多实验
- 与 CVPR/ICCV 同级，双年一届

## 表达偏好

| 维度 | 偏好 |
|------|------|
| 人称 | "we" |
| 语态 | 主动优先 |
| 标题 | 任务+方法型 |
| 风格 | 图驱动。14 页允许更充分的表达，但不意味着更啰嗦——精炼原则不变 |

## 红线

与 CVPR 一致：实验不足 / novelty 不足 / overclaim / 图质量差 / Related Work 不全。

**ECCV 特有**：14 页给了更多篇幅，但对清晰度的期待也更高——审稿人不接受用更多页来掩盖逻辑不清。

## 标题风格

与 CVPR 风格一致。参考 CVPR 的标题风格矩阵。

# TACL (Transactions of the ACL)

- **类型**：期刊（NLP 顶刊）
- **领域**：自然语言处理

## 篇幅结构

| 项 | 说明 |
|----|------|
| 正文限制 | 无硬性限制，典型 15-25 页 |
| 附录 | 无限制 |
| 结构 | IMRaD + 更详尽的 Related Work |
| 摘要 | ≤ 250 词 |

**结构惯例**：
- 相对于 ACL/EMNLP 会议论文，期刊论文期待：
  - 更全面的 Related Work（不仅仅是 nearest neighbor）
  - 更详细的理论分析或更系统的实验
  - 更深入的 Discussion（不仅是 Limitations 一段）
- 滚动审稿制：提交→修改→重审，可以多轮修订

## 表达偏好

| 维度 | 偏好 |
|------|------|
| 人称 | "we" |
| 语态 | 主动优先 |
| 标题 | 信息型，但可稍长于会议论文标题 |
| 风格 | 比会议论文更详尽，可接受更多背景铺垫和讨论 |

## 红线

1. **深度不足**：期刊审稿人期待比会议论文更深的理论/实证贡献
2. **只加实验不改正文**：会议论文加两页实验直接投期刊 → 被拒
3. **Related Work 覆盖不全**：期刊期待更全面的文献覆盖
4. 其余同 ACL（overclaim / 不可复现）

## 标题风格

- **主导模式**：信息型，比会议论文更正式
  - "Method: A Framework for Task" — 期刊式冒号标题占比高于会议论文
  - 更少用设问句标题
- **禁止**：空转标题

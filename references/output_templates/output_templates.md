# 输出模板

> 各模式的标准输出格式。SKILL.md 工作流 → 此处模板。

## 规范检查报告

```markdown
## 写作规范诊断报告

**范围**：<摘要/引言/全文，N 词/字>
**语言**：<中文/英文>

### 诊断摘要（按严重度排序）

1. 🔴 <合并多条相关规则的关键问题一>
2. 🔴/🟡 <关键问题二>
3. 🟡 <关键问题三>
（如有更多关键问题可延长至 5 条；合并相关规则——如多处论证问题→一条"论证链路缺陷"）

### 完整诊断

| 规则 | 结果 | 位置/说明 |
|------|:--:|------|
| 2.1 主动语态 | ✅ | — |
| 2.2 短句 | ⚠️ | 第3段第1句 31词，接近上限 |
| 2.3 一句一主张 | ❌ | 第1段第2句含3个主张，建议拆分 |
| ... | | |

### 违规详情

**规则 2.3 一句一主张** — ❌ 违规
> 位置：第1段第2句
> [原句]
> 
> 建议：
> [修改后版本]

### 统计

| | 数量 |
|------|:--:|
| ✅ 通过 | 12 |
| ⚠️ 警告 | 3 |
| ❌ 违规 | 2 |
| N/A | 3 |
| 范围 | 27/28 |

💡 需要对某个问题方向（论证层 / 措辞层 / 去AI化）深挖一轮吗？
```

## 佳作评析报告

```markdown
## 佳作评析报告

**范围**：<论文名/作者/年份>
**语言**：<中文/英文>

### 逐规则评析

| 规则 | 表现 | 评析 |
|------|:--:|------|
| 2.1 主动语态 | ✅ | 全文自然使用 "we"，无被动堆砌 |
| 4.7 标题 | ⚠️ | "Attention Is All You Need" 故意不传达发现——制造悬念。经典标题策略，但刻意为之才有效 |
| ... | | |

### 值得学习的亮点

1. 规则 X — <具体好在哪>
2. 规则 Y — <值得效仿的具体技术>

### 有意识突破

| 规则 | 论文做法 | 效果评价 | 是否建议效仿 |
|------|---------|---------|:--:|
| 4.7 | 标题只传达方法不传达发现 | 塑造了研究范式名称，传世价值大于信息量 | ⚠️ 只有范式首创论文适合 |
```

## 阶段出口汇报（v3.0 新增）

```markdown
📋 [模式名] 完成

**进展**（≥2 条，≤5 条）
- 具体产出了什么
- 关键数据或结论

**偏离**（如无偏离则省略）
- 和原计划的差异 + 原因

**待拍板**（如无需拍板则明确说）
- 需要你决定的事（附 AI 建议）

**风险**（如无则明确说）
- AI 观察到的问题或担忧

**未知**（如无则明确说）
- 对后续有影响但当前不确定的事
```
